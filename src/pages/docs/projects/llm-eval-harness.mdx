<h1 class="text-4xl font-bold mb-6 gradient-text">LLM Eval Harness</h1>
<p class="text-text-muted mb-8">
  Reusable golden-set evaluation harness for LLM and RAG systems: faithfulness, answer relevance,
  and correctness metrics with LLM-as-judge and offline heuristic fallbacks.
</p>

<div class="gradient-border p-6 mb-6">
  <h2 class="text-2xl font-bold text-text mb-3">Overview</h2>
  <p class="text-text-muted mb-4">
    A CLI + Python library that loads golden sets (YAML of questions, golden answers, and context),
    scores model outputs, and produces JSON + Markdown reports with per-metric mean/min/max —
    perfect for CI regression gates.
  </p>
</div>

<div class="gradient-border p-6 mb-6">
  <h2 class="text-2xl font-bold text-text mb-3">Metrics</h2>
  {/* prettier-ignore */}
  <ul class="space-y-2">
  <li class="flex items-start gap-2.5 text-text-muted"><span class="text-primary mt-[0.25em] shrink-0" aria-hidden="true">▸</span><span><strong class="text-text">Faithfulness</strong> — how well the answer is grounded in the retrieved context</span></li>
  <li class="flex items-start gap-2.5 text-text-muted"><span class="text-primary mt-[0.25em] shrink-0" aria-hidden="true">▸</span><span><strong class="text-text">Answer relevance</strong> — how on-topic the answer is to the question</span></li>
  <li class="flex items-start gap-2.5 text-text-muted"><span class="text-primary mt-[0.25em] shrink-0" aria-hidden="true">▸</span><span><strong class="text-text">Correctness</strong> — lexical overlap against the golden answer</span></li>
</ul>
</div>

<div class="gradient-border p-6 mb-6">
  <h2 class="text-2xl font-bold text-text mb-3">LLM-as-Judge + Offline Fallback</h2>
  <p class="text-text-muted mb-4">
    When an OpenAI-compatible API key is available, an LLM judges each pair on a 0–1 scale. Without
    a key, deterministic lexical scorers kick in — so evals run in CI for free and the pipeline
    never blocks on external services.
  </p>
</div>
