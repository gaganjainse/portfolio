<h1 class="text-4xl font-bold mb-6 gradient-text">Architecture</h1>
{/* prettier-ignore */}
<p class="text-text-muted mb-8">Overview of the architecture patterns used across my AI and systems projects.</p>

  <div class="space-y-8">
    <section class="gradient-border p-6">
      <h2 class="text-2xl font-bold text-text mb-3">SheshAOS — Governance-First AI Operating Environment</h2>
      {/* prettier-ignore */}
<p class="text-text-muted mb-4">Governance-first, event-sourced AI operating environment written in Rust — 9 workspace crates + CLI, 877+ passing tests, full CI/CD.</p>
      <ul class="space-y-2">
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Policy-enforced agent kernel: models propose actions, the kernel validates and records every state change</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Append-only event-sourced audit trail with reversible, permissioned actions</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Provider-agnostic LLM layer: OpenAI-compatible and Anthropic streaming, LiteLLM routing, local-first inference</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Native terminal emulation (PTY + VT100), SSH multiplexing, secrets vault, CLI/TUI/GUI/RPC interfaces</span>
        </li>
      </ul>
    </section>

    <section class="gradient-border p-6">
      <h2 class="text-2xl font-bold text-text mb-3">RAG Service — Hybrid Retrieval Pipeline</h2>
      {/* prettier-ignore */}

<p class="text-text-muted mb-4">FastAPI RAG service combining dense embeddings and BM25-style keyword scoring, fused with Reciprocal Rank Fusion (RRF) over a persistent ChromaDB vector store.</p>
      <ul class="space-y-2">
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Word-based chunking with overlap; embeddings via sentence-transformers or a deterministic hashing fallback</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Grounded answers with source citations via any OpenAI-compatible chat endpoint (offline echo fallback)</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>28 tests; evaluated end-to-end with the LLM Eval Harness</span>
        </li>
      </ul>
    </section>

    <section class="gradient-border p-6">
      <h2 class="text-2xl font-bold text-text mb-3">LLM Eval Harness — Golden-Set Evaluation</h2>
      {/* prettier-ignore */}

<p class="text-text-muted mb-4">Reusable CLI + library that scores LLM/RAG outputs against golden sets and emits CI-ready JSON + Markdown reports.</p>
      <ul class="space-y-2">
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Metrics: faithfulness, answer relevance, correctness (per-case + mean/min/max summary)</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>LLM-as-judge when an API key is present; offline lexical fallbacks keep CI free</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>15 tests; gates the RAG Service pipeline</span>
        </li>
      </ul>
    </section>

    <section class="gradient-border p-6">
      <h2 class="text-2xl font-bold text-text mb-3">shesh-ecosystem — Local-First AI Body</h2>
      {/* prettier-ignore */}

<p class="text-text-muted mb-4">Federated, local-first AI body (Brain + Mind + Soma) for CachyOS/Hyprland — orchestrator, manifests, gates, 22 components.</p>
      <ul class="space-y-2">
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Brain (governance kernel), Mind (models/planning/memory), Soma (sensors/actuators)</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>Orchestrator manifest with 22 components, 3 channels (stable/canary/devel), SHA256-audited locks</span>
        </li>
        <li class="flex items-start gap-2.5 text-text-muted">
          <span class="text-primary mt-[0.35em] shrink-0" aria-hidden="true">▸</span>
          <span>shesh-audit GuardedMCP policy (allow/confirm/deny) + hash-chained audit + Kernel bridge; swarm via GitHub Issues atomic locks</span>
        </li>
      </ul>
    </section>
